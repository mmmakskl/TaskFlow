# TaskFlow Implementation Plan

> **For agentic workers:** Execute inline using superpowers:executing-plans. No delegation is needed.

**Goal:** Deliver a private Telegram task bot with peer ratings, immutable scoring snapshots, configurable penalties, and verified persistent deployment.

**Architecture:** One FastAPI web service receives authenticated Telegram webhooks. Aiogram handlers call services; services use repositories and async PostgreSQL transactions. PostgreSQL also stores FSM, inbox, outbox, and immutable score events.

**Tech Stack:** Python 3.12+, aiogram 3, FastAPI, SQLAlchemy 2, asyncpg, Alembic, pytest, Docker, Render, Supabase.

**Spec:** `docs/PRODUCT.md`, reflecting the user-provided MASTER PROMPT.

## Global Constraints

- Exactly two configured Telegram IDs; private chats only.
- Opposite user rates tasks 1..10000; completion credits the snapshot at completed_at.
- Reopen reverses the original completion in its original week; audit preserves history.
- Penalty snapshots never change when configuration changes.
- Rating notifications at most one per 60 minutes per user, including concurrent requests.
- All schema creation through Alembic; no production filesystem data.
- No intermediary REST API, JWT, auth Redis, or polling.
- Destructive changes need confirmation; callbacks check current state and version.
- Secrets only environment; no token or credentials in logs.
