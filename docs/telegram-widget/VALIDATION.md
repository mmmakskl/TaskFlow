# Проверка статических макетов

26 ноября 2026. Это проверка проектных файлов, а не работающего Telegram Widgets.

- Chrome headless отрисовал [обзор двух тем](overview.png), ширина 840 px, высота 1180 px. Изображение просмотрено: две темы, показатели участников и действия читаются без обрезки.
- [Узкий вариант](mobile.png) отрисован с шириной содержимого 320 px. На macOS Chrome сохраняет минимальную ширину окна больше заданной; для этого снимка временная копия HTML ограничивала `html, body` до 320 px. Рабочие файлы не менялись. Все 12 карточек проверены сравнением `scrollWidth` и `clientWidth`: переполнений нет. Это не эмуляция устройства.
- HTML разобран стандартным Python `HTMLParser`: 12 секций (6 состояний × 2 темы), в списке каждой темы ровно 5 задач, нет script, внешних URL или зависимостей.
- Контраст рассчитан по относительной яркости sRGB. Минимум в проверенных текстовых парах — 5.27:1, минимум границы кнопки — 3.62:1.
