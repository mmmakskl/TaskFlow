# Активность и карточки: контракт первой версии

Доска принадлежит одному участнику и хранит только конфигурацию трекеров; каталог тегов общий. Архивирование тега сохраняет связи с задачами, шаблонами и трекерами. Теги шаблона копируются при создании задачи и не синхронизируются впоследствии. Несколько выбранных тегов трекера объединяются по правилу «хотя бы один», каждая задача учитывается один раз на трекер.

Источники данных намеренно различаются:

- Выполнения: текущие задачи в статусе DONE, с датой completed_at в DEFAULT_TIMEZONE; личная задача относится к исполнителю, общая — к обоим. Возврат из DONE исключает её до следующего законного завершения.
- Объём: quantity из неизменяемого template_snapshot только для PER_TIME или PER_QUANTITY с подходящей единицей; estimated_minutes не является фактическим временем.
- Баллы завершённых задач: awarded_points, снимок выданной награды; историю счёта и компенсации сохраняют существующие score events. Изменение тегов не меняет начисления.
- Серии: локальные календарные дни с ненулевым значением показателя, ограниченные выбранным годом. Текущая серия заканчивается сегодня или вчера; предыдущий год не продолжает её.

Годовая сетка начинается в понедельник, показывает будущие даты отдельно и имеет фиксированную легенду. Уточнение дня показывает только соответствующие задачи с пагинацией. Переходы в Mini App не являются авторизацией: действуют существующие проверки initData и прав доступа.

В чате Rich Messages используют отдельный метод Bot API и обновление rich_message; обычный HTML — только fallback при подтверждённой неподдержке. Неоднозначная ошибка сети не разрешает повторную отправку.
